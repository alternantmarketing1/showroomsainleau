# Showroom 3D SAINLEAU

Maquettes 3D interactives pour présenter le mobilier SAINLEAU aux clients :

- **Chambre collectivité** : 1 personne (lit simple), 2 personnes (lit double), 3 personnes (lit superposé + lit simple), avec la composition et les prix HT de sainleau.com.
- **Studio salon et cuisine** : gamme appartements diffus du catalogue mobilier 2026, pour 1, 2 ou 3 personnes (18, 25 et 30 m²), avec les références.

Tout tient dans `index.html` : une seule page, sans dépendance locale (Three.js est chargé depuis jsDelivr, les images sont intégrées).

## Liens directs

Ajouter à l'adresse de la page :

- `#studio-1`, `#studio-2`, `#studio-3`
